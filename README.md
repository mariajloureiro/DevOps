# 🚀 Disciplina de DevOps

Este repositório serve como centralizador para os materiais de estudo, anotações teóricas e links para todos os projetos práticos desenvolvidos ao longo da disciplina de **DevOps**. 

O objetivo principal do curso é compreender e aplicar na prática os conceitos de **Integração Contínua (CI)**, **Entrega Contínua (CD)**, **Automação**, **Containerização** e **Orquestração de Infraestrutura**.

---

## 📌 Conteúdo do Repositório

* `docs/`: Anotações de aula, resumos teóricos e guias de estudo organizados por tópicos.
