# 🚀 Disciplina de DevOps

Este repositório contém os materiais de estudo, atividades práticas e projetos desenvolvidos ao longo da matéria de **DevOps**. O objetivo é aplicar os conceitos de integração, entrega contínua, automação e infraestrutura.

---

## 📌 Conteúdo do Repositório

* **Docs:** Resumos teóricos e anotações de aula.
* **Exercícios:** Atividades práticas divididas por tópicos/módulos.
* **Projetos:** Automações de infraestrutura e pipelines de CI/CD.
